# 星が降らない夜に、君を選んだ。

## 概要
架空のアニメ作品の公式サイトを想定して制作したWebサイトです。
作品の世界観を壊さないよう、情報量を抑えたシンプルな構成としました。

## コンセプト
「夜・星・静寂」をキーワードに、
余白や配色を用いて落ち着いた雰囲気を表現しています。

## 工夫した点
- 余白を多く取り、静けさを感じるレイアウト
- スクロールに応じた背景色の変化による演出
- 最低限の情報設計で公式サイトらしさを意識

## 使用技術
- HTML / CSS / JavaScript / Figma
